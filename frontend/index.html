API endpoints reference
MethodPathDescription
GET/healthLiveness check — { ok: true }
GET/statusConnection state — connecting, qr_pending, connected, disconnected
GET/qrPairing QR code as a PNG image, while a scan is pending
POST/logoutLog out the linked device and clear the session (triggers a new QR code)
GET/groupsList groups this account participates in, with their JIDs
GET/conversationsList saved conversations (local, works while disconnected) with last-message preview
POST/sendSend a message — body { to, message } (phone number or group JID)
GET/messages/:toRecent stored messages for a conversation — query ?limit= (default 50, max 500)
POST/messages/:to/historyRequest older messages be backfilled — body { count }, results arrive async
POST/mcpMCP JSON-RPC endpoint (Streamable HTTP) — same tools as the stdio server
GET/pluginsList available plugins, with their config JSON schema (if any)
GET/plugins/assignmentsList every conversation that currently has a plugin attached
GET/plugins/registrationsList raw remote plugin registrations (id, baseUrl, health) — not just assigned ones
DELETE/plugins/registrations/:pluginIdAdmin removal of a plugin registration (no secret needed) — for the management screen
POST/plugins/registerRemote plugin self-registration — body { pluginId, name, description, baseUrl, configJsonSchema }, header X-Plugin-Secret to re-register
DELETE/plugins/registerRemote plugin unregisters itself — body { pluginId }, header X-Plugin-Secret
POST/plugins/heartbeatRemote plugin liveness ping — body { pluginId }, header X-Plugin-Secret
POST/plugins/callbackRemote plugin's async reply — body { pluginId, requestId, chatJid, reply }, header X-Plugin-Secret
GET/conversations/:to/pluginGet the plugin currently assigned to a conversation, if any
PUT/conversations/:to/pluginAssign a plugin to a conversation — body { pluginId, config }
PATCH/conversations/:to/pluginEnable/disable the assigned plugin — body { enabled }
DELETE/conversations/:to/pluginDetach the plugin from a conversation
