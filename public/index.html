API endpoints reference
MethodPathDescription
GET/healthLiveness check — { ok: true }
GET/statusConnection state — connecting, qr_pending, connected, disconnected
GET/qrPairing QR code as a PNG image, while a scan is pending
POST/logoutLog out the linked device and clear the session (triggers a new QR code)
GET/groupsList groups this account participates in, with their JIDs
GET/conversationsList saved conversations (local, works while disconnected) with last-message preview
POST/sendSend a message — body { to, message } (phone number or group JID)
GET/messages/:toRecent stored messages for a conversation — query ?limit= (default 50, max 500)
POST/messages/:to/historyRequest older messages be backfilled — body { count }, results arrive async
POST/mcpMCP JSON-RPC endpoint (Streamable HTTP) — same tools as the stdio server
